
# Gestión de Estudiantes
## Actividad formativa 3: Herencia

### Descripción
Proyecto desarrollado en Java para demostrar el uso de la herencia.

### Clases del proyecto

- Estudiante: clase base que contiene los datos generales.
- EstudiantePresencial: clase derivada para estudiantes presenciales.
- EstudianteEnLinea: clase derivada para estudiantes en línea.
- Main: clase principal donde se ejecuta el programa.

### Conceptos aplicados

- Herencia.
- Reutilización de código.
- Sobrescritura de métodos.
- Constructores.
- Palabra reservada super.

### Lenguaje utilizado
Java.
