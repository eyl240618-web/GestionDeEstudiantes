Gestión de Estudiantes

Descripción
Este proyecto consiste en una aplicación sencilla desarrollada en Java para practicar los fundamentos de la programación orientada a objetos.

Objetivo
Comprender el uso de clases, atributos, constructores, objetos y métodos mediante un ejemplo práctico.

Funcionamiento
La aplicación crea objetos de tipo `Estudiante` y muestra el nombre, la edad y la carrera de cada uno.

Tecnologías utilizadas
- Lenguaje de programación Java.
- Programiz Online Compiler.
- GitHub para almacenar y compartir el código fuente.
